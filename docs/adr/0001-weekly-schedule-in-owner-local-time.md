# Недельное Расписание хранится в локальном времени Владельца

Расписание хранится как дни недели и локальные интервалы времени вместе с IANA-часовым поясом Владельца (например, `Asia/Almaty`), а не как фиксированные UTC-интервалы: при переходах на летнее время «09:00–18:00» должно оставаться 09:00–18:00 по часам Владельца. В UTC хранятся только конкретные моменты (начало и конец Брони), API передаёт их в ISO 8601 с `Z`. Слоты рассчитывает backend, Гость видит их в часовом поясе своего браузера.

Решение принято заранее, до реализации Расписания: текущая фича (главная страница) его ещё не использует.
