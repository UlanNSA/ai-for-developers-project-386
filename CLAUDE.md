# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

For the general agent guidelines, see [`AGENTS.md`](./AGENTS.md). The rest of this file contains only Claude-specific notes.

## Do not touch

- `.github/workflows/hexlet-check.yml` is auto-generated by Hexlet: never edit, delete or rename it (nor the repo). Own CI lives in `.github/workflows/ci.yml`.

## Claude-specific notes

- The project uses contract-first API design (`api/*.tsp` → committed `api/openapi/openapi.yaml` → generated SDK in `frontend/src/api/generated/`). See `AGENTS.md` and `README.md` for commands.
- Backend routes/DTOs are implemented by hand in Kotlin/Ktor; keep them in sync with the TypeSpec contract.
- Generated SDK files must never be edited manually; regenerate with `sdk:generate`.
- Environment configuration comes from env vars; never commit secrets.
- For full architecture, domain rules, deployment and proxy details, see `README.md`, `docs/domain-rules.md`, `docs/adr/`, and `GLOSSARY.md`.
